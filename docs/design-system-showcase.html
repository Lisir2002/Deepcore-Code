动效：Spring 物理双轨

3.5 · 五 · D16 · v4 吸收 M3 Expressive

v4 核心升级：吸收 M3 Expressive 运动物理——spring 取代固定时长曲线。spring 可中断、速度感知：手势中途接管平滑续接，正是流式 AI 输出高频重定目标的场景所需。Spatial 类允许 ≤6% 过冲回弹；Effects 类（色彩/透明度）禁止过冲（damping=1.0）。点击对比 spring 与 tween 的手感差异：

Spatial · spring(0.6, 800) fast · 过冲

无障碍工程

十 · D10 · 硬约束

A11y 由系统解析、风格包不可覆盖（D10）。loader 强制校验对比度矩阵；12.2 单测锁死 brand 包全部配对。

对比度硬校验

WCAG 2.1 相对亮度模型（10.1）
onPrimary ↔ primary（正文）5.1:1 ≥4.5 ✓
textPrimary ↔ surface16.2:1 ✓
textSecondary ↔ surface6.8:1 ✓
textTertiary ↔ surface（弱信息）3.2:1 ≥3 ✓
暗色最高层表面按 15.8:1 底面亮度上限倒推（v4）

排版四要素 10.5 · v4 吸收 W3C

系统字号缩放到 200% 不破版
行高 ≥ 1.5× 字号（正文默认）
段后距 ≥ 2.0× 字号（富文本块）
字距 ≥ 0.12×（label 小字号）
词距 ≥ 0.16×（西文混排）
另两条铁律：不靠 hover 传信息；关键信息不进 placeholder

reduce motion 与读屏

10.3 / 10.4
系统动画缩放 = 0 → 全部转场直切
pressed/dragged 缩放同步禁用

设计决策时间线

1.3 · D5–D20
D5–D7v1 定稿

风格包可切换/可插拔/高度自定义；dynamicColor 关；先定稿后实施。

D8–D11v2 深化

语义令牌唯一真理 + M3 单向派生（镜像断言）；theme.json delta 覆盖；A11y 硬约束；新增令牌走评审。

brand色板定调

黑白灰主调、蓝紫点缀、红绿状态——冷灰 14 档 + 明暗双板 + 对比度全标注。

D12–D14v3 行为层

八态机 + State Overlay 弃 ripple；八转场模式 × 档位绑定；三段式五型骨架。

D15v3.1 子组件

浮层三变体（confirm/status/notice）/ 下拉 / Toast+Banner / 表单族收编，lint 四条新规则。

D16v4 · spring 双轨

全网调研吸收 M3 Expressive 运动物理：spatial（可过冲）/ effects（禁过冲）× 三档速度；tween 仅兜底。

v4深色海拔体系

暗色抬升变亮四档表 + 15.8:1 基准 + 去饱和规则 + 禁 glow。

v4A11y 排版四要素

行高/段后/字距/词距下限进组件默认值；拇指区 + 8dp 间距规则。

D17v4 · 趋势立场

白名单：Bento 排布 / emphasized 字体 / 微交互三件套 / 微肌理。黑名单：玻璃拟态 / 新拟态 / 高饱和 / 炫技粒子。

T8.1 →（T8.2 ∥ T8.5）→ T8.3 → T8.4；与 M1 真实模型并行推进。
